# ProComm Field Unit Visual Reference

This folder preserves the original field-unit photo-documentation PDF and six
rendered page images used for enclosure, XLR-bank, display, antenna, and
connector-layout reference.

- `procomm-field-unit-photo-documentation.pdf` is the archived source.
- `procomm_field_unit-1.png` through `procomm_field_unit-6.png` are rendered
  reference pages.

The legacy ProComm hardware is a visual and architectural reference only. The
Radxa CM5 product uses its own PCB, AK5558VN/AK4458VN TDM audio architecture,
power calculations, and final mechanical drawings.
