# Controlled Harnesses

This folder contains cable-assembly definitions for the Radxa CM5 ProComm
field unit.

- `H01-PSU-24V.md`: bottom-mounted RPS-400-24-C 24 V output to PWR-SELECT
- `H01-PSU-24V-BOM.csv`: exact H01 connector and termination parts
- `H02-PSU-AC.md`: fused C14 inlet to PSU CN1 mains harness and PE boundary
- `PSU-Harness-Interfaces.svg` and `.png`: factory visual separating the H01
  and H02 pinouts

Harness lengths are prototype values until the first fully dressed mechanical
article is measured. Do not release a production cable solely from a concept
floorplan.
